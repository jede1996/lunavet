# Test-Driven Development (TDD) Skill

Guarantees 100% test coverage and regression prevention by writing failing tests before business logic.

## Workflow
1. **Red Phase**: Write unit/integration tests describing expected behavior, edge cases, and error conditions. Run tests to confirm they fail as expected.
2. **Green Phase**: Implement the absolute minimum code required to make tests pass cleanly.
3. **Refactor Phase**: Optimize architecture, extract utilities, eliminate duplication, and verify tests remain green with 0 stderr warnings.
