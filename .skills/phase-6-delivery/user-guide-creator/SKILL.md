# User Guide Creator Skill

Produce guías de usuario claras, accesibles y orientadas a roles clínicos y de clientes.

## Directivas
1. **Enfoque en la Tarea**: Estructurado por lo que el usuario necesita lograr ("Cómo registrar un nuevo paciente", "Cómo realizar el corte Z de caja").
2. **Cero Jerga de Desarrollador**: Elimina términos como "endpoints", "JWT", "localStorage", "props" o "payloads". Habla de "botones", "pantallas", "recetas" y "alertas".
3. **Callouts y Notas Claras**: Utiliza alertas estándar (Nota, Importante, Precaución) para pasos delicados como medicamentos controlados o cobros.
4. **Sinergia con Humanizer**: Lenguaje empático, natural, sin formalismos robóticos.
