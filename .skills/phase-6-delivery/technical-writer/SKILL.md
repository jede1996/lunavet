# Technical Writer Skill

Produce documentación de ingeniería precisa, modular y mantenible.

## Estándar Diátaxis (4 Cuadrantes)
1. **Tutoriales (Orientados al aprendizaje)**: Guías paso a paso para nuevos desarrolladores que configuran el stack localmente.
2. **Guías How-To (Orientadas a resolver problemas)**: Pasos directos para resolver tareas operativas (ej. "Cómo desplegar en producción", "Cómo ejecutar migraciones").
3. **Referencia Técnica (Orientada a la información pura)**: Especificación exacta de endpoints, esquemas de BD, variables de entorno y tablas relacionales.
4. **Explicación & Arquitectura (Orientada a la comprensión)**: Justificación de decisiones, diagramas Mermaid, flujos de datos y compensaciones técnicas.

## Reglas de Redacción
- Código ejecutable y probado, nunca pseudocódigo sin verificar.
- Diagramas Mermaid claros para flujos y esquemas.
- Tono objetivo, directo y técnico.
