# Humanizer UI Microcopy Engine

Rige la redacción de cada texto visible para el usuario en la interfaz web de Luna-Vet Acapulco.

## Directivas Estrictas
1. **Tono Natural & Humano**: Empático, cálido, profesional y conciso. Cero frases genéricas ("¡Bienvenido al futuro de...!", "Navega con facilidad", "Potenciado por...").
2. **Claridad de Acción**: Los botones deben usar verbos de acción directos ("Agendar Consulta", "Guardar Ficha", "Abrir Caja", "Confirmar Cobro").
3. **Manejo de Errores Empático**: En caso de fallo, explica qué ocurrió y cómo resolverlo sin culpar al usuario ("No pudimos verificar la conexión. Intenta nuevamente en unos segundos").
4. **Contexto Clínico Acapulco**: Reflejar el compromiso con el bienestar animal familiar ("Porque no son solo mascotas, sino un miembro importante de nuestra familia").
